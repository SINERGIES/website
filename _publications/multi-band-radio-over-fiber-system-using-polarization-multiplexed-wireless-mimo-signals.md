The users need more flexibility access network and high throughput using wired or wireless connection. Moreover, Wireless Local Area Network (WLAN) can work in different bands at carrier frequency 2.4 GHz, 5 GHz or 60 GHz. To offer such variety, we propose a multiservice system using Radio over Fiber (RoF) technology, which can transport wired Base Band (BB), 5 GHz Multi Input Multiple Output (MIMO) and 60 GHz MIMO signals simultaneously over Single Mode Fiber (SMF) using polarization multiplexing technique. In this paper, the performance of the proposed system is analyzed in function of Bit Error Ratio (BER) and eye diagram. By using the optimum system parameters; we have achieved 2.6 Gb/s for BB, 2 x 2 MIMO 5GHz and 2 x 2 MIMO 60GHz over 40 km for a BER below of 10(-9).
