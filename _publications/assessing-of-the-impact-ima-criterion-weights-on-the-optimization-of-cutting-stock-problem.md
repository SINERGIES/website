This paper provides a sensitivity assessment of the Item Maximal Area (IMA) criterion parameters within the framework of the cutting stock problem (CSP). The evaluated criterion identifies the suitable couple of an empty rectangle and its associated piece for placement, aiming to minimize trim loss when designing two-dimensional (2D) cutting patterns. This sensitivity analysis is performed using a set of twenty instances of CSP. Computational experiments indicate that the parameters of the studied criterion influence the resulting trim loss. Additionally, appropriate values for these criterion parameters should be tuned based on the specific instance being considered.
