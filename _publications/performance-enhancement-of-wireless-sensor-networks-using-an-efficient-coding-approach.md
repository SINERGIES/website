The Random Linear Network Coding (RLNC) has been investigated as a promising solution for improve transmission reliability; however, it is highly susceptible to errors. In wireless sensor networks (WSN), The problem resemblance to a column vector on the generator matrix of Low-Density Parity-Check (LDPC) matrix is caused by the important similarity between received symbols from the cluster head (CH). To deal with this problem, we have to reduce BER. The principal objective of this paper is to use an efficient coding approach based on the RNC and LDPC codes using TDMA (Time Division Multiple Access) technology. The coding techniques employed in this paper are focused on enhance planning to report error-bit (BER) vs. signal-to-noise (SNR), between CHs and the base station (BS) node in dense WSN, while describing each point examining effective use of the proposed algorithm.
